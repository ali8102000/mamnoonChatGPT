# تدقيق أمني إضافي لخدمة الخرائط — 17 نوفمبر 2026

## الحالة التي تم التحقق منها
- مشروع Supabase: `enteiolvirenbhkyskgb`.
- الوظيفة المنشورة: `maps-proxy`، الإصدار 2، الحالة ACTIVE، و`verify_jwt=true`.
- نسخة المصدر في الفرع تتطابق مع محتوى الوظيفة المنشورة كما تم استرجاعه من Supabase.
- جميع نقاط الدخول تتطلب Bearer token صالحاً ويجري التحقق من المستخدم عبر `auth.getUser(token)`.
- لا يوجد حالياً حد طلبات لكل مستخدم داخل الوظيفة، ولا توجد آلية موثقة لمنع إساءة استخدام استدعاءات Google Routes / Places أو Photon.

## صلاحيات قاعدة البيانات
الدالة `public.search_map_place_suggestions(text,text,integer)`:
- هي `SECURITY DEFINER` و`STABLE`.
- صلاحية EXECUTE الحالية: `postgres` و`service_role` فقط؛ لا توجد صلاحية مباشرة لـ `authenticated`.
- لذلك استخدام عميل service role في البحث الحالي سببه منح الصلاحيات الحالية، وليس مجرد اختيار تنفيذي.
- الجدولان `map_place_suggestions` و`map_place_search_cache` لديهما RLS مفعّل بلا سياسات مباشرة. لا يجوز فتح الوصول المباشر إليهما لمجرد إزالة service role.

## ملاحظات أمنية يجب معالجتها قبل إعلان اكتمال النقل
1. إضافة RPC قراءة محدودة للمستخدم المسجل فقط، تعرض حقول الأماكن العامة النشطة فقط، وتتحقق من `auth.uid()`، وتحدد طول الاستعلام وعدد النتائج والمحافظة، ثم نقل عمليات القراءة من service role إلى عميل المستخدم.
2. إبقاء الكتابة إلى cache وsuggestions داخل سياق موثوق فقط، مع حد طلبات ومحددات تكرار لكل مستخدم/عنوان بحث، وعدم منح المستخدمين صلاحية كتابة مباشرة.
3. إضافة rate limiting موثوق على مستوى قاعدة البيانات أو بوابة الخدمة لاستدعاءات `autocomplete`, `details`, `reverse`, `route`؛ حد داخل ذاكرة Edge Function وحده لا يكفي لأنه غير مشترك بين النسخ.
4. تقييد CORS إلى نطاقات ممنون الفعلية للويب، مع بقاء التحقق من JWT إلزامياً للأندرويد.
5. إضافة اختبارات رفض للطلبات غير المسجلة، واختبارات صلاحيات للقراءة والكتابة، واختبار حد الطلبات، واختبار مفاتيح Google الغائبة/المقيدة.
6. لا يتم تعطيل مسار التوافق القديم في Vercel قبل نجاح اختبارات الويب وAndroid الحية.

## القرار
لا تغييرات مباشرة على RLS أو grants أو البيانات في هذا التدقيق. التوصية هي إنشاء RPC آمن للقراءة وحدود طلبات كإضافات مستقلة، ثم اختبارها على فرع/بيئة اختبار قبل أي تحويل إنتاجي.
